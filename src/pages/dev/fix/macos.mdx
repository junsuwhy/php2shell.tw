## 1. 檢查

<CommandBlock label="列出已安裝的 PHP 公式與版本" code={`brew list --versions | grep '^php'
php -v`} />

對照 homebrew-core 公式裡的上游原始碼版本（2026-10-22 查詢）：

| 公式 | 公式裡的上游 tarball |
| --- | --- |
| php | php-8.5.12.tar.xz |
| php@8.4 | php-8.4.27.tar.xz |
| php@8.3 | php-8.3.36.tar.xz |
| php@8.2 | php-8.2.35.tar.xz |

同一台機器可能裝了好幾個 `php@` 公式，PATH 上的那一支不一定是本機網頁伺服器在用的那一支。

## 2. 更新

<CommandBlock label="更新 Homebrew 並升級 PHP 公式（依你裝的公式改 php@8.3 等）" code={`brew update
brew upgrade php`} />

若你用的是更舊、已不在 homebrew-core 的分支（例如第三方 tap 的 php@7.4），見[舊版本策略](/dev/eol/)。

## 3. 重啟

<CommandBlock label="用 brew services 跑 php-fpm 時重啟它" code={`brew services restart php`} />

本機的網頁伺服器，以及開著的開發伺服器（例如 Laravel Valet、`php -S`）也一起重啟。

## 4. 驗證

- 再跑一次 `php -v`，並確認本機網頁伺服器連到的是更新後的那一支。
- 開發機上的版本對上之後，別忘了正式環境要照它自己的平台頁修補。
