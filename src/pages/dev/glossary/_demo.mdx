### 第一次出現才標註：標題裡的 RCE 不算

這次兩個 CVE 的官方後果都包含未授權 RCE，修補之後要重啟所有 worker。

### 程式碼與連結裡的詞不標註

設定名稱寫成行內程式碼 `session.upload_progress.enabled` 時不標註；寫在連結文字裡的 [OPcache](/dev/mitigation/) 也一樣。

```sh
php -v   # 程式碼區塊裡的 PHP-FPM、OPcache 不標註
```

正文裡第一次寫到 OPcache，才會在這一段下方出現註解。

### 長詞優先，不在英文單字中間誤配

跑 PHP-FPM 的主機也要一起確認；後面單獨寫 FPM 時，因為是同一個詞，不再標註。像 workers 這種較長的英文單字，也不會被拆出 worker 來標。
