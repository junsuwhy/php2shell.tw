# Spec Delta

## Purpose

讓開發者頁第一次遇到專有名詞時，不用離開該段就能看到註解；非技術頁不啟用自動標註，行動裝置也不必靠懸停。

## ADDED Requirements

### Requirement: 每頁首次出現的詞在段落下方註解

系統 SHALL 在建置時依名詞表的詞與別名，把開發者內容裡每一頁第一次出現的詞標出來，並在該段落下方顯示註解。行動裝置 MUST 不依賴懸停就能讀到註解。程式碼區塊、標題與連結內 MUST NOT 標註。非技術區 MUST NOT 啟用自動標註。

#### Scenario: 段落下方出現註解

- **WHEN** 開發者頁的正文第一次出現名詞表中的詞或別名
- **THEN** 該詞以底線標記
- **AND** 同一段落下方列出註解，內容是名詞表裡給開發者的註

#### Scenario: 同一頁只標第一次

- **WHEN** 同一個詞在同一頁後面再次出現
- **THEN** 後續出現的詞不再標註，也不重複那段註解

#### Scenario: 程式碼標題與連結不標註

- **WHEN** 詞出現在程式碼區塊、標題或連結文字裡
- **THEN** 這些位置不標註，也不因此觸發段落註解

#### Scenario: 行動裝置不用懸停

- **WHEN** 訪客以窄視窗或沒有懸停的裝置閱讀已標註的段落
- **THEN** 註解仍直接出現在該段落下方

#### Scenario: 非技術區不啟用

- **WHEN** 訪客閱讀任一 `/basic/` 頁面
- **THEN** 頁面沒有自動標註的詞，也沒有自動產生的段落註解
