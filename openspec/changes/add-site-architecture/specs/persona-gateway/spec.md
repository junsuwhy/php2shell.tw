# Spec Delta

## Purpose

讓訪客自己選身份進入對應的閱讀區，系統只記住選擇、不擅自跳轉，並在三區之間提供草案規定的導流與共用入口。

## ADDED Requirements

### Requirement: 首頁選擇身份且不自動跳轉

網站 SHALL 在首頁提供三張身份卡片，並顯示事件一句話、目前修補版本與最後更新時間。訪客選過的身份 MUST 只記在該瀏覽器，下次進站顯示「繼續上次的身份」，且 MUST NOT 自動跳轉。

#### Scenario: 首次進站

- **WHEN** 訪客第一次開啟首頁 `/`
- **THEN** 頁面顯示非技術人員、軟體開發人員、吃瓜群眾三張卡片
- **AND** 頁面同時顯示事件一句話、目前修補版本與最後更新時間

#### Scenario: 選擇身份

- **WHEN** 訪客在首頁選擇其中一張身份卡片
- **THEN** 非技術人員進入 `/basic/`、軟體開發人員進入 `/dev/`、吃瓜群眾進入 `/news/`

#### Scenario: 再次進站不自動跳轉

- **WHEN** 同一瀏覽器已經有身份選擇，訪客再次開啟首頁
- **THEN** 首頁仍停在身份選擇，並顯示「繼續上次的身份」
- **AND** 網站不開啟上次的區，直到訪客自己點繼續或另選身份

#### Scenario: 沒有已存選擇

- **WHEN** 該瀏覽器沒有存過身份選擇
- **THEN** 首頁不顯示「繼續上次的身份」

### Requirement: 跨區導流與共用入口

每個身份區的頁首 SHALL 提供切換身份的入口。三區 MUST 提供草案規定的跨區連結。找不到頁 MUST 提供三種身份入口。關於頁 MUST 說明網站目的、資料來源原則與免責聲明，並說明使用 GA4 流量統計；站長聯絡 email 已設定時 MUST 顯示，未設定時 MUST NOT 顯示空連結。

#### Scenario: 頁首切換身份

- **WHEN** 訪客位於任一身份區的頁面
- **THEN** 頁首可以切換到另外兩個身份區

#### Scenario: 非技術區導向開發者區

- **WHEN** 訪客在非技術區看到「想看技術細節？給你的工程師這頁」
- **THEN** 該連結通往 `/dev/`

#### Scenario: 開發者區導向非技術區

- **WHEN** 訪客在開發者區看到「要跟老闆解釋？丟這頁給他」
- **THEN** 該連結通往 `/basic/`

#### Scenario: 吃瓜區導向檢查精靈

- **WHEN** 訪客在吃瓜區看到「我自己也有網站」
- **THEN** 該連結通往 `/basic/check/`

#### Scenario: 找不到頁

- **WHEN** 訪客開啟不存在的路徑
- **THEN** 找不到頁提供三個身份入口，分別通往 `/basic/`、`/dev/` 與 `/news/`

#### Scenario: 關於頁

- **WHEN** 訪客開啟 `/about/`
- **THEN** 頁面說明網站目的、資料來源原則與免責聲明
- **AND** 頁面說明本站使用 GA4 流量統計

#### Scenario: 聯絡 email

- **WHEN** `site.yaml` 的 `contact_email` 有值
- **THEN** 關於頁與頁尾顯示該 email 的聯絡連結
- **AND** 值為空時兩處都不顯示聯絡連結
