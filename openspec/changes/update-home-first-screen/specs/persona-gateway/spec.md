# Spec Delta

## Purpose

讓從社群用手機點進首頁的訪客，不必捲動就知道要立即更新、該更新到哪一版，以及網站老闆下一步該點哪裡。

## ADDED Requirements

### Requirement: 首頁第一屏優先呈現立即更新與主要行動

首頁 SHALL 在身份卡之前顯示「請立即更新」公告、各支援分支的修補版本，以及連到 `/basic/act/` 的主要按鈕「我有網站，現在該做什麼」。修補版本 MUST 由 `src/data/facts.yaml` 的 `fixed` 產生，MUST NOT 寫死在頁面裡。塗鴉主視覺 SHALL 保留，手機上可縮小高度；桌機版 MUST 維持滿版主視覺。

#### Scenario: 手機第一屏

- **WHEN** 訪客以約 390×844 的手機畫面開啟首頁 `/`
- **THEN** 不捲動即可看到「請立即更新」公告、`facts.fixed` 列出的所有修補版本，以及「我有網站，現在該做什麼」按鈕
- **AND** 塗鴉主視覺仍顯示在頁首下方，高度比桌機矮

#### Scenario: 修補版本更新

- **WHEN** 維護者修改 `facts.yaml` 的 `fixed`
- **THEN** 首頁公告的版本跟著改變，不需要修改頁面程式碼

#### Scenario: 點主要按鈕

- **WHEN** 訪客點「我有網站，現在該做什麼」
- **THEN** 前往 `/basic/act/`

#### Scenario: 手機上的身份卡

- **WHEN** 訪客在寬度 600px 以下的畫面捲到身份卡
- **THEN** 身份卡以矮的橫條呈現，插圖縮成小方塊，整張卡片仍可點擊
