## 摘要

WordPress.org 新聞稿指出，PHP 專案發布安全更新，修補 PHP 裡的兩項重大漏洞。這不是 WordPress 專屬問題，沒有、也不計劃發布 WordPress 更新。

## 重點

- 在網站裡查看 PHP 版本的路徑是：工具 → 網站健康狀態 → 資訊 → 伺服器（Tools > Site Health > Info > Server）。主機控制台也可能看得到。
- PHP 8.2 以前不再從 PHP 專案收到安全更新。自行管理主機且還停在更舊版本時，應考慮先把伺服器下線，再準備升級。
- 新聞稿引用英國 NCSC：不能立刻完成緩解時，應考慮讓系統下線，直到可以完整緩解。
- 文中沒有寫出 8.5.12、8.4.27、8.3.36、8.2.35。

## 值得引用

> No WordPress update is required or planned for these issues.
